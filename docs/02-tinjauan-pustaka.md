# BAB 2 — TINJAUAN PUSTAKA

## 2.1 Literasi Digital
Literasi digital adalah kemampuan individu untuk menemukan, mengevaluasi, dan menggunakan informasi secara kritis melalui teknologi digital. Dalam konteks keamanan, literasi digital mencakup kesadaran terhadap phishing dan *quishing*.

## 2.2 Quishing (QR Code Phishing)
*Quishing* adalah teknik rekayasa sosial di mana penyerang menggunakan QR Code untuk menyembunyikan URL berbahaya. Karena QR Code berbentuk gambar, korban tidak dapat melihat domain tujuan secara langsung, sehingga lebih mudah tertipu dibandingkan tautan teks biasa.

## 2.3 Rule Engine Heuristik
Heuristik adalah pendekatan pemecahan masalah yang menggunakan aturan praktis (*rule of thumb*). Dalam keamanan siber, *Rule Engine Heuristik* digunakan untuk mendeteksi pola-pola mencurigakan pada URL (seperti penggunaan IP, shortlink, atau kemiripan brand) tanpa harus bergantung pada *database blocklist* raksasa.

## 2.4 Progressive Web App (PWA)
PWA adalah jenis aplikasi web yang dapat diinstal pada perangkat pengguna dan memiliki kemampuan untuk bekerja secara offline (melalui *Service Worker*). PWA menjembatani pengalaman aplikasi *native* dengan aksesibilitas web, sangat cocok untuk alat bantu yang membutuhkan akses cepat dan privasi (pemrosesan lokal).
